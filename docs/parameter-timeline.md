# 参数关键帧时间线

## 编辑

- 载入模型后，时间线列出实际参数及部件透明度。组合模型按角色、参数组和模型部件区分同名参数。
- 关闭参数的动画开关时，滑块修改基础值；开启后，滑块或“打帧”在播放头位置写入关键帧。
- 素材面板的“上轨”和拖放都会转换动作、表情为参数数据。素材区间以外的数据及其他参数保留。
- 点击关键帧查看时间、数值、插值。Shift 点击多选；拖动移动，Delete 删除，Cmd/Ctrl+C、V 复制粘贴，Cmd/Ctrl+Z 撤销，Shift+Cmd/Ctrl+Z 重做。
- “曲线”只展开选中参数；贝塞尔曲线的控制点可拖动。双击参数轨可以打帧。
- 素材分组可整体移动；两侧边缘裁剪或延长末帧。检查器里的速度单独控制变速，“恢复裁剪”恢复工作曲线的完整区间。手动修改的素材关键帧随分组移动，原始素材曲线单独保留。
- 暂停时可以任意拖动播放头；停止播放保持当前画面。音频、字幕仍使用独立轨。

## 数据与渲染

工程版本为 V2，实际动画保存在 `animation.tracks`。参数定位由角色、部件、参数 ID 构成，不包含临时模型服务器端口。`animation.groups` 保存来源、工作曲线、原始曲线、裁剪及速度信息，不触发 SDK 动作播放器。

`src/animation/engine.ts` 负责曲线求值与素材编辑；`importers.ts` 读取 motion3、MTN、表情；`runtime.ts` 连接 Cubism SDK。预览、播放、素材预览及离线导出使用同一求值路径。

运行时关闭模型自主更新，物理使用 120 Hz 固定步长及每秒快照。非整步求值不会污染快照。编辑使最早受影响时间之后的缓存失效。口型由音频预先分析为 120 Hz 曲线；手动动画参数最后覆盖自动效果、口型及物理结果。

V1 工程在模型加载后转换，音频、字幕与角色静态设置保留。迁移失败时保留旧片段并显示修复入口。自动保存升级前为旧 V1 文件保存带日期的副本；工程包直接保存关键帧，V2 重开不需要重新读取动作文件。模型资源仍引用本机模型库。

## 验证

```sh
npm test
npx tsc -b
npm run build
npm run lint
cd src-tauri && cargo check
```

可选真实模型测试：

```sh
L2D_TEST_MODEL=/absolute/path/to/model.model3.json npm test
```

测试覆盖四种插值、原始采样与亚帧、表情合成、范围、区间替换、素材编辑、撤销、序列化、迁移、组合参数定位、物理随机跳转及口型优先级。真实模型测试读取项目使用的 Cubism Core 和 SDK，比较随机跳转与直接求值的参数、透明度及全部 drawable 顶点。

2026-09-30 验证结果：19 项测试通过；真实 Cubism 模型具有 184 个参数、87 个部件、352 个 drawable。原生 Tauri 窗口验证了动作导入、暂停拖动、组合部件独立参数、一次数值编辑的一步撤销和 V2 工程保存重开。MOV 与 WebM 各实际导出 2 秒、30 fps、60 帧，均确认透明通道。

当前真实资源验证覆盖 Cubism 3/4/5 运行时及 JSONL；Cubism 2 的 MTN 转换和 SDK 参数读取有自动测试，但没有可用的 Cubism 2 完整模型进行原生画面验收。WebGAL 的入口、导入流程及专用 Rust 命令已按用户要求注释停用，源码保留。工程音频和外部模型恢复仍使用共享资源服务。
